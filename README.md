# Cacau

Instaladores do [Cacau](https://cacau.si), o bloco de notas com IA para reuniões.

| Sistema | Download |
|---|---|
| macOS 11+ (Apple Silicon) | [Cacau-mac-arm64.dmg](https://github.com/OkamiOps/cacau-releases/releases/latest/download/Cacau-mac-arm64.dmg) |
| Windows 10/11 (x64) | [Cacau-windows-x64.exe](https://github.com/OkamiOps/cacau-releases/releases/latest/download/Cacau-windows-x64.exe) |
| Linux (x64) | [Cacau-linux-x86_64.AppImage](https://github.com/OkamiOps/cacau-releases/releases/latest/download/Cacau-linux-x86_64.AppImage) |

Os links acima sempre baixam a versão mais recente. Versões anteriores e notas de cada uma: [Releases](https://github.com/OkamiOps/cacau-releases/releases).

O instalador do macOS é assinado e notarizado pela Apple. Cada release traz o `SHA256SUMS.txt` para conferir os arquivos.
